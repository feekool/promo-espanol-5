Настройка

Как развернуть рабочее место за 5 минут

Если вы умеете заполнять Google-документ, вы справитесь. Технического бэкенда нет.

1. Аккаунт на GitHub

Зарегистрируйтесь на github.com (бесплатно, без карты)

2. Возьмите готовый шаблон

Откройте feekool.github.io → нажмите "Use this template" → "Create a new repository". Назовите: mi-profe-espanol

3. Включите GitHub Pages

Settings → Pages → Source: main → Save. Через минуту сайт доступен по адресу:

https://ваш-ник.github.io/mi-profe-espanol

4. Настройте под репетитора

Откройте файлы в репозитории. Вставьте своё имя, фото, приветствие на испанском. Создайте папки для первых 2–3 учеников. Отправьте им ссылки.

5. Работайте

Загружайте ДЗ, публикуйте грамматические разборы, собирайте ответы. Всё структурировано. Всё сохраняется.

💡 Совет для репетиторов: В шаблоне уже есть разделы «Gramática», «Vocabulario», «Tareas», «Progreso». Просто скопируйте папку /alumno-template, переименуйте и отправьте ссылку новому ученику. Масштабируйте без усилий.
